Banco de Dados MySQL

Projeto desenvolvido para prática e estudo de banco de dados relacionais utilizando MySQL.

Conteúdos praticados
Criação de tabelas
Relacionamentos entre tabelas
Chaves primárias (PRIMARY KEY)
Chaves estrangeiras (FOREIGN KEY)
Constraints
JOINs (INNER JOIN, LEFT JOIN e RIGHT JOIN)
Consultas com SELECT
Inserção, atualização e remoção de dados
Modelagem de banco de dados
Relacionamentos N utilizando tabelas intermediárias
Estrutura

O arquivo schema.sql contém a estrutura completa do banco de dados, incluindo tabelas, relacionamentos e restrições.
