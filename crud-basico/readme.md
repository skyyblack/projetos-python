# Gerenciador de Tarefas em Python 📝

Projeto desenvolvido em Python com o objetivo de praticar conceitos fundamentais da linguagem, como listas, dicionários, funções, loops e manipulação de dados.

## 📌 Sobre o projeto

Este é um sistema simples de gerenciamento de tarefas executado pelo terminal.

O usuário pode:
- Adicionar novas tarefas
- Definir o nível de prioridade
- Marcar tarefas como concluídas
- Listar todas as tarefas cadastradas
- Alterar o status de uma tarefa
- Remover tarefas

## 🚀 Funcionalidades

### Adicionar tarefa
O usuário informa:
- Nome da tarefa
- Nível de prioridade
- Se a tarefa já foi concluída ou não

### Listar tarefas
Exibe todas as tarefas cadastradas mostrando:

- Índice da tarefa
- Nome
- Status (feita ou não feita)
- Prioridade

### Alterar tarefa
Permite marcar uma tarefa como concluída através do índice informado.

### Remover tarefa
Remove uma tarefa da lista utilizando seu índice.
